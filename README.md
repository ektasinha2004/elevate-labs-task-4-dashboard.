# Elevate Labs Task 4 – Sales Dashboard

## 📊 Project Overview

This project is a Sales Dashboard created using Microsoft Power BI as part of Elevate Labs Task 4.

The dashboard provides an interactive analysis of sales performance and profitability across different regions, categories, sub-categories, states, segments, and months.

## 🛠️ Tools Used

- Microsoft Power BI
- Superstore Sales Dataset
- Data Visualization
- Interactive Dashboarding

## 📈 Dashboard Features

### Sales Performance Dashboard
- Total Sales
- Sales by Region
- Sales by Sub-Category
- Sales by State
- Sales by Category
- Sales by Segment
- Monthly Sales Trend

### Profit Analysis Dashboard
- Total Profit
- Profit by Category
- Profit by Region
- Profit by Segment
- Profit by Sub-Category
- Monthly Profit Trend
- Interactive filters and slicers

## 📂 Project Files

- `Task4_Sales_Dashboard_Final.pbix` – Power BI dashboard file
- `task4_Sales_Dashboard_Report.pdf` – Dashboard report/screenshots

## 🎯 Objective

To create an interactive Power BI dashboard that transforms sales data into meaningful visual insights and helps analyze business performance and profitability.
